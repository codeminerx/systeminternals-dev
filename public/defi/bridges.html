      7What are Bridge Routers?

      Blockchains are inherently siloed environments. Ethereum knows about Ethereum; Arbitrum knows about Arbitrum. They can't natively read each other's state or transfer assets between them.

      A bridge router performs three functions: it locks or burns assets on the source chain, verifies the transaction occurred through some consensus mechanism, and then mints or releases assets on the destination chain.

      🔒
      Lock-and-Mint
      Lock assets, mint wrapped tokens. WBTC, canonical L2 bridges.
      🔥
      Burn-and-Mint
      Burn on source, mint on dest. LayerZero OFT, Axelar GMP.
      ⚡
      Atomic Swaps
      Trustless cross-chain exchange. Both succeed or both revert.
      💧
      Liquidity Networks
      AMM-style pools across chains. Stargate, Curve cross-chain.

      15Glossary
      Bridge Router
      A protocol enabling asset or data transfer between distinct blockchain networks.
      Lock-and-Mint
      Bridge pattern: lock on Chain A, mint wrapped tokens on Chain B.
      Burn-and-Mint
      Bridge pattern: burn on Chain A, mint equivalent on Chain B.
      Atomic Swap
      Trustless cross-chain exchange where both transactions succeed or both revert.
      Liquidity Network
      AMM-style bridge model: LPs fund pools on multiple chains, routing takes a fee.
      DVN
      Decentralized Verifier Network — LayerZero's multi-party verification model.
      LayerZero
      Omnichain messaging protocol providing trustless delivery for cross-chain data.
      Canonical Bridge
      Bridge using the native chain-recognized mechanism for cross-chain communication.
      Wrapped Token
      Token representing an asset from another chain 1:1. WETH is the canonical example.
      Relayer
      Off-chain actor delivering transaction proofs between chains, compensated with bridge fees.
